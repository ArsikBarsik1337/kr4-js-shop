## Каталог товаров

- В массиве `products` хранятся 10 товаров трёх категорий. Обязательные поля каждого товара — `id`, `title`, `category`, `price` и `isAvailable`.
- Поиск находит товар по части названия без учёта регистра. Его можно сочетать с фильтром категории.
- Сортировка работает по названию и по цене с учётом скидки. Функция сортирует копию массива, поэтому исходный порядок сохраняется.
- Карточки создаются через JavaScript. При изменении фильтра обновляются список и количество результатов. Если совпадений нет, появляется кнопка сброса.

## Формы и безопасный вывод

- Перед оформлением заказа проверяются имя, e-mail, телефон, адрес и согласие на обработку данных.
- Ошибка появляется под полем, а фокус переходит к первому полю с ошибкой. Во время имитации отправки кнопка заблокирована. После успешной проверки на странице появляется номер заявки.
- Элементы находятся через `querySelector`, создаются через `createElement` и добавляются через `append`. Для классов используется `classList`, для событий — `addEventListener`.
- Названия товаров и сообщения записываются через `textContent`, поэтому браузер отображает их как текст. Для ошибок и подтверждений используются сообщения на странице.

## Самостоятельные доработки

- Корзина поддерживает изменение количества и удаление позиций. Сумма пересчитывается через `reduce` с учётом количества, скидок и промокода.
- Избранное доступно через шапку и фильтр каталога. Корзина, избранное, промокод и выбор темы сохраняются в `localStorage`.
- Каталог разбит на страницы по шесть товаров. Можно задать диапазон цен и оставить только товары в наличии.
- Быстрая заявка открывается в диалоге с названием выбранного товара. Тёмная тема доступна на всех страницах.

## JavaScript-файлы

- `data.js` — 10 товаров трёх категорий и два промокода. У каждого товара уникальный id, название title, категория category, числовая цена price, флаг наличия isAvailable, скидка, признак новинки, описание и изображение.
- `storage.js` — Ключи localStorage, чтение и запись JSON, обработка недоступного хранилища.
- `boot.js` — До показа страницы выбирает сохранённую или системную тему, устанавливает data-theme на html и класс js для адаптивного меню.
- `main.js` — Переключение темы и синхронизация вкладок, мобильное меню, прокрутка вверх, название карты.
- `utils.js` — Форматирование цены и скидки, поиск по id, создание DOM-элементов и текстовых сообщений.
- `catalog.js` — Поиск по части названия без учёта регистра, фильтры категории, цены, наличия и избранного. Сортирует копию массива по итоговой цене или названию. Делит результат на страницы по 6 и строит карточки.
- `product.js` — Читает id из адреса, показывает характеристики и действия с товаром либо сообщение об ошибке.
- `favorites.js` — Добавляет и убирает избранные товары, сохраняет выбор и обновляет счётчики.
- `cart.js` — Добавляет и удаляет позиции, меняет количество, считает стоимость через reduce, применяет промокод.
- `cart-view.js` — Выводит строки корзины, скидки и итог. Обновляет сводку на странице заказа.
- `modal.js` — Открывает диалог быстрой заявки для выбранного товара и сбрасывает форму при закрытии.
- `validation.js` — Проверяет поля, показывает ошибки и подтверждение, имитирует отправку и очищает форму.
